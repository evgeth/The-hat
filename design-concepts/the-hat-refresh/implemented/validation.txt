Device build: Debug iphoneos, signed with the project's development team. The CLI deployment-target override is 15.0 for the installed Xcode; project deployment settings are unchanged. The single-window scene configuration supports iOS 27.

Latest interaction checks (iPhone 17 Pro Max, iOS 27.2): tap outside a player field dismisses the keyboard; switching fields and tapping Done still work. The handoff count and menu have distinct frames. The primary label reads Hold to Start immediately. Both hold actions use elapsed time.

Word review: a 31-word modal list was exercised with row insets, two status changes, scroll and Save. Correct is green (check), returned is warm grey (return arrow), and mistake is terracotta (cross). The Not guessed button uses the same neutral colour after time expires in either mode.

Optional word skips default off at New Game. Checked a real setup-to-round flow and skip → guess → skip on a three-word hat: only the two skipped words return for the next turn; there is no deduction. An overtime return ends the turn without drawing a new word.
